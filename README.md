# alessianicoletti0-jpg.github.io
Sito portfolio personale di Alessia Nicoletti, UX/UI Designer. 
Il sito presenta le competenze, i progetti e l'esperienza professionale, con una pagina CV e una pagina contatti.

🚧 Sito online, in fase di aggiornamento continuo.

## 🛠️ Tecnologie utilizzate

- **HTML5**
- **CSS3 + SCSS (Sass)** — variabili e mixin per gestire colori, bottoni e media query in modo centralizzato
- **Bootstrap 5.3.8** (via CDN) — componenti come badge, alert e progress bar
- **Google Fonts** — Lora e Playfair Display
- **EmailJS** — invio del form di contatti direttamente dal browser, senza backend
